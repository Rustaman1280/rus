TENTANG IT CLUB

IT Club SMKN 1 Garut adalah organisasi ekstrakurikuler berbasis riset, karya teknis, dan kompetisi teknologi informasi.

Didirikan sebagai pusat inkubasi bakat digital di SMKN 1 Garut, IT Club berfokus pada pembekalan keterampilan praktis di luar kurikulum reguler. Kami melatih siswa untuk menguasai standar pemrograman modern, aplikasi, Internet of Things (IoT), hingga pengelolaan jaringan.

Setiap anggota akan dibimbing melalui alur kerja nyata (real-world workflow), proyek kolaboratif, serta persiapan menghadapi LKS (Lomba Kompetensi Siswa) dan berbagai hackathon tingkat regional maupun nasional.

01. PRESISI

STANDAR INDUSTRI

Mengintegrasikan alur kerja teknis profesional dan kode yang bersih (clean code).

02. KOLABORASI

PROYEK TIM

Pengalaman langsung membangun perangkat lunak dan infrastruktur secara kolaboratif.

03. PRESTASI

KOMPETISI

Fokus pembinaan intensif untuk perlombaan LKS, Hackathon, dan IT Olympiad.

DIVISI KEAHLIAN

DIV-01 SOFTWARE & UI/UX

APP DIVISION

Fokus pada pengembangan aplikasi (mobile & web), rekayasa perangkat lunak, arsitektur frontend & backend, perancangan antarmuka UI/UX, serta pemecahan masalah algoritma.

  • MOBILE DEV
  • WEB DEV
  • UI/UX DESIGN
  • REST API
  • SOFTWARE ARCHITECTURE
  • ALGORITHMS
DIV-02 INFRASTRUCTURE & HARDWARE

NETWORK & IOT DIVISION

Fokus pada penguasaan infrastruktur jaringan komputer, instalasi & perancangan Internet of Things (IoT), manajemen server Linux, Cloud Computing, serta Keamanan Siber.

  • COMPUTER NETWORKING
  • INTERNET OF THINGS (IOT)
  • LINUX SERVER
  • CYBER SECURITY
  • CLOUD & SYSADMIN
